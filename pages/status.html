Current status

What is true today, including what is not finished.

Early stage prototype.

SilentVoice AI is not registered, not certified and not clinically validated. Its regulatory classification has not been determined.

The help button asks the browser to speak a request aloud. It sends an email only if recipients and an email server are configured for the installation, and there is no confirmation that anyone read it. It does not contact emergency services. Do not rely on it in an emergency.

Testing

In September 2026 four non-developer test participants tried the prototype. One of the four participants retested the navigation fix, see issue #2. This was informal usability testing.

Your data

Camera images are processed in the browser. The code does not send them to the SilentVoice server or anywhere else.

When an AI phrase is requested, the selected phrase and the name of the selected card set are sent to the SilentVoice server. Only the phrase is passed to OpenAI.

Speech is produced by the browser. Depending on the browser and the voice, the browser may send the phrase text to the company that provides the voice. SilentVoice AI cannot reliably tell which voices do this.

If the browser has no speech feature, the phrase text is sent to the SilentVoice server. The server does not produce sound, so nothing is heard.

A request for assistance contacts the SilentVoice server. If recipients and an email server are configured, the server sends an email with a fixed request phrase and the time.

The contact form sends your name, email address and message by email. The application does not store these details in its own files or database, whether or not sending succeeds. After a message is sent, the server keeps the connection address in memory for up to an hour to limit repeated messages.

Nothing is for sale and there is no payment system.
